## Use and governance

Use these originals as **style references only**. A style prompt must cite at least two of them as visual references; no unrelated generator, scripted flat infographic, generic science collage or multiple-figure montage qualifies. The originals are not scientific approval or compliant 1920 × 1080 publication assets. Owner must expressly approve style fidelity of the first regenerated image before wider batches. Scientific correctness is a separate QA gate.

The locked production and approval standard is in [draft PR #6](https://github.com/SymTechVenturesOrg/symtechventures.github.io/pull/6). **Do not merge or deploy PRs based on this registry.**
